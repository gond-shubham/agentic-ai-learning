# Agentic AI Learning

## About This Repository

This repository documents my learning journey towards designing, developing, testing, and deploying Agentic AI applications.

The goal is to build a strong foundation in software engineering, Python, APIs, Large Language Models (LLMs), and AI agent development through structured learning and practical projects.

Rather than focusing only on theory, this journey emphasises understanding concepts and applying them through hands-on exercises and projects.

## Learning Approach

- Understand the purpose of each concept before implementing it.
- Learn through practical examples and exercises.
- Follow a structured software development workflow.
- Build projects incrementally, starting with simple implementations.
- Practise testing, debugging, and documenting code.
- Gradually progress towards developing reliable Agentic AI applications.

## Long-Term Goal

To develop the knowledge and practical skills required to independently design, build, test, debug, and deploy Agentic AI applications.
